**两个文件说明：**

**`LikeButton.vue`（子组件）** — 纯展示，所有数据来自 props，无任何内部状态和 API 调用：
- `newsId` / `liked` / `likeCount` / `loading` 四个 props 传入
- 只 emit 一个事件 `toggle(newsId)`，父组件决定调什么接口
- 未点赞：镂空蓝色边框按钮；已点赞：实心蓝色填充；loading 时转圈并禁用
- 数量超过 1 万自动显示 `x.xw`；操作完成后弹出气泡提示

**`index.vue`（父组件）** — 持有全部点赞状态，负责接口通信：
- `likeState` reactive 对象统一管理 `liked` / `likeCount` / `loading`
- `fetchLikeState()` 在新闻加载完成后调用，初始化点赞状态
- `handleLikeToggle()` 处理子组件 toggle 事件，调用接口后更新状态
- `MOCK_LIKE_DATA` 是临时 mock，对接真实 API 时只需替换 `fetchLikeState` 和 `handleLikeToggle` 里注释掉的两行

**对接后端接口时替换的两处：**
```typescript
// fetchLikeState 里
const res = await fetch(`/api/likes/status?newsId=${newsId}`, { headers: { Authorization: `Bearer ${token}` } })
const countRes = await fetch(`/api/likes/count?newsId=${newsId}`)

// handleLikeToggle 里
const res = await fetch('/api/likes/toggle', {
    method: 'POST',
    headers: { Authorization: `Bearer ${token}`, 'Content-Type': 'application/json' },
    body: JSON.stringify({ newsId })
})
const data = await res.json()
likeState.liked = data.liked
likeState.likeCount = data.likeCount
```
